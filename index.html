/ 03 Case Study

A defensible LLM pipeline on Azure.

stagiaire · 01
MX4.AI
Rabat, Maroc
May 2025 · Cloud & AI
Production deployment

One month. One LLM. Zero shortcuts.

A focused sprint where I owned the deployment side of a Llama-based product end-to-end: cluster, GPU sizing, monitoring, security, cost. The fastest education I’ve had so far.

  • Deployment. Provisioned an AKS cluster with a dedicated GPU nodepool. Containerised the inference service and rolled it out with HPA-based autoscaling.
  • Cost optimisation. Tuned pod requests/limits and the autoscaling strategy so we’d only burn GPU cycles when actually serving traffic.
  • Observability. Wired Azure Monitor + Log Analytics so latency, throughput and node pressure were visible in real time.
  • Security. Managed identities for secret access, isolated VNet, clean separation between data, control and model planes.
  • Documentation. Wrote a deployment runbook so the team could ship the next model without me in the loop.
